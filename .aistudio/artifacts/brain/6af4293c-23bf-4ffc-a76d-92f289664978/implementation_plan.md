# สรุปการพัฒนาระบบคลังสินค้า: แจ้งเตือนสต็อกติดลบ และการจัดการรายการค้างจ่าย (Backorder Management)

## ฟีเจอร์ที่พัฒนาเสร็จสมบูรณ์

### 1. ระบบแจ้งเตือนสต็อกติดลบ และทางลัดปรับสต็อก (Negative Stock Alert & Quick Adjustment)
- **การตรวจจับและแจ้งเตือน:**
  - ตรวจจับรายการสินค้าที่มีสต็อกติดลบ (`current_stock < 0`) เช่น -150,000 หรือ -5,001
  - แสดง Banner แจ้งเตือนสีแดงเด่นชัดทั้งในหน้า **Dashboard Overview** และหน้า **คลังสินค้า (InventoryView)**:
    *"พบรายการสินค้าสต็อกติดลบ [X] รายการ ต้องการปรับสต็อกให้เป็นปัจจุบันหรือไม่?"*
- **ปุ่มทางลัด (Quick Action):**
  - แสดงปุ่ม **"ปรับสต็อก"** สีแดงเด่นชัดข้างตัวเลขยอดติดลบในตาราง
  - เมื่อคลิก จะเปิดหน้าต่าง **"ปรับยอดสต็อก (Stock Adjustment)"** ทันที พร้อมปรับค่า Default จำนวนนับจริงเป็น `0` และใส่หมายเหตุให้อัตโนมัติ เพื่อให้เจ้าหน้าที่กรอกยอดจริงแล้วบันทึกเป็น Transaction `ADJUSTMENT` ได้ทันที

---

### 2. ฟังก์ชันการลบรายการค้างจ่ายทีละหลายรายการ (Bulk Delete Pending Items)
- **Checkbox & Action Bar:**
  - เพิ่ม Checkbox เลือกทั้งหมด (Select All) ที่หัวตาราง และหน้าทุกแถวรายการค้างจ่าย
  - เมื่อมีการเลือกรายการ จะแสดง Action Bar สีฟ้าด้านบน ระบุจำนวนรายการที่เลือก, จำนวนหน่วยงาน และมูลค่ารวม
- **การลบพร้อมกัน (Bulk Delete):**
  - ปุ่ม **"ลบรายการที่เลือก"** พร้อมหน้าต่างยืนยัน (Confirmation Modal) แสดงรายการที่จะถูกยกเลิก
  - ทำการยกเลิกและนำรายการออกจากค้างจ่ายใน Database พร้อมกันในครั้งเดียว (`cancelBackorderItemsBatch`)

---

### 3. ฟังก์ชันรวบรายการค้างจ่าย สร้างเป็นใบเบิกใหม่ตามหน่วยงาน (Batch Requisition Creation)
- **การจัดกลุ่มและสร้างใบเบิกใหม่:**
  - ปุ่ม **"รวบเบิกที่เลือก"** ใน Action Bar และแถบเครื่องมือ
  - จัดกลุ่มรายการค้างจ่ายที่เลือกตามหน่วยงาน (`departmentId`)
  - รันเลขที่ใบเบิกใหม่อัตโนมัติเรียงต่อกัน (Consecutive Requisition Numbers เช่น `#6910058`, `#6910059`) โดยไม่กระทบหรือแก้ไขประวัติในใบเบิกเดิม
  - อัปเดตรายการค้างจ่ายเดิมเป็นสถานะโอนแล้ว (`Fulfilled` ด้วยเหตุผล `โอนไปสร้างเป็นใบเบิกใหม่แล้ว`) เพื่อป้องกันการเบิกซ้ำ
  - ส่งใบเบิกใหม่เข้าสู่ Workflow สถานะ **"กำลังจัดของ (Picking)"** เพื่อให้เจ้าหน้าที่คลังจัดและจ่ายของตามกระบวนการปกติทันที
  - แสดงหน้าต่างสรุปผลลัพธ์ (Success Modal) แสดงเลขที่ใบเบิกใหม่ที่สร้างขึ้นแยกตามหน่วยงาน
